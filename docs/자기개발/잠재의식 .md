# 잠재의식

## 한 문장 정의

잠재의식은 `내가 의식하지 않아도 자동으로 나오는 생각/감정/행동 패턴`이다.

## 왜 중요한가

- 삶의 많은 반응이 자동으로 나온다.
- 자동 반응이 부정적이면 의욕, 자신감, 행동력이 같이 떨어진다.
- 자동 반응을 바꾸면 같은 상황에서도 선택이 달라진다.

## 바꾸는 핵심 원리

`반복 + 행동`이 잠재의식을 바꾼다.

- 말만 반복: 효과가 약함
- 행동만 시도: 오래 못 감
- 말 + 행동을 같이 반복: 습관으로 고정됨

## 실전 루틴 (쉽게)

### 루틴 1: 수면 패턴 고정
1. 바꿀 문장을 정한다.  
`나는 12시자서 7시 일어나는 사람이다.`
2. 트리거를 고정한다.  
`23:30` 휴대폰 종료 -> `23:40` 세면 -> `24:00` 소등.
3. 기상 직후 행동을 붙인다.  
알람 끄고 바로 물 한 컵 + 커튼 열기.
4. 14일 체크한다.  
취침/기상 시간을 체크박스로 기록한다.


### 루틴 2: 운동 루틴 고정
1. 문장  
`나는 매일 스쿼트100 팔굽혀펴기100 풀업20 런지 100  러닝 30분하는사람이다..`


## 문장은 어느 정도 구체적으로?

`정체성 + 행동 + 시간/횟수`까지 들어가면 충분히 좋다.

- 약한 문장: `나는 성공한 사람이다.`
- 좋은 문장: `나는 평일 밤 12시에 자고 아침 7시에 일어나는 사람이다.`
- 좋은 문장: `나는 매일 저녁 20분 공부하는 사람이다.`

너무 거창한 문장보다, `오늘 바로 실행 가능한 문장`이 잠재의식 변화에 훨씬 효과적이다.
